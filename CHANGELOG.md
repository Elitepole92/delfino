# Versionen

Schema **Haupt.Neben.Fix**:
- **Hauptversion** (1, 2, 3 …): grosser Schritt, der das Spiel spuerbar veraendert.
- **Nebenversion** (x.1, x.2 …): neue Funktion.
- **Fix** (x.x.1, x.x.2 …): Korrektur oder kleine Optik-Aenderung.

Die sichtbare Version steht in `delfino/VERSION`. Intern zaehlt GitHub zusaetzlich eine
Build-Nummer hoch; nur die vergleicht der Stick beim Update. „Build“ unten = Nummer der
alten Releases (v1 … v20).
